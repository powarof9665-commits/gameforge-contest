# GAMEFORGE — مسابقه بازی‌سازی

نسخه استاتیک آماده انتشار روی GitHub Pages.

## انتشار
1. یک Repository عمومی بساز.
2. `index.html` و `.nojekyll` را در ریشه آپلود کن.
3. Settings → Pages → Deploy from a branch → `main` / `/ (root)` → Save.
4. لینک Visit site را برای شرکت‌کننده‌ها بفرست.

نکته: فرم ارسال در این نسخه فقط در LocalStorage همان مرورگر ذخیره می‌شود. برای ثبت واقعی و مشترک، فرم باید به یک سرویس فرم/Backend و دیتابیس متصل شود.
